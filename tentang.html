Tentang PatunganYuk

Aplikasi web minimalis untuk praktik kolaborasi Git & GitHub tim 7 orang.

Beranda Tentang

PatunganYuk dibuat bersama oleh Joel, Irene, Tristan, Desvita, Gicell, Michael, dan Alexander menggunakan HTML, CSS, dan JavaScript murni tanpa library eksternal.

Versi Aplikasi: v1.0.0 • Alur kolaborasi linear tanpa konflik.
