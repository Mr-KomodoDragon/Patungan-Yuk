# PatunganYuk — Catatan Patungan Tim 7 Orang

Aplikasi web GUI minimalis (HTML, CSS, JavaScript murni) untuk mencatat pengeluaran tim dan menghitung otomatis pembagian biaya rata-rata per orang.

## Cara Menjalankan

1. Clone repository ini ke komputer lokal.
2. Klik dua kali file `index.html` untuk membukanya di browser.
